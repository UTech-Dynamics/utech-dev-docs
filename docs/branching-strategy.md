## Branch Naming

Branch naming guidance lives in [engineering-guidelines.md](engineering-guidelines.md).

Use the same short-lived feature branch pattern described there:

- `feat/<name>` for new features
- `fix/<name>` for bug fixes
- `chore/<name>` for maintenance work

Keep branch names short, descriptive, and focused on one change.

Examples:

- `feat/product-catalog-normalization`
- `fix/order-state-validation`
- `chore/update-test-docs`
